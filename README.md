# FocusTimer Releases & Installation

Official download repository for **FocusTimer** (macOS).

## 🚀 Download & Installation

1. Download the latest `.dmg` installer from the **[Releases Section](https://github.com/DrAndreasEisele/FocusTimer_release/releases/latest)**.
2. Open the `.dmg` file and drag **FocusTimer.app** into your **Applications** folder.
3. Launch FocusTimer from Applications or Spotlight.

## 📋 System Requirements
- **macOS:** 14.0 (Sonoma) or newer
- **Apple Silicon & Intel:** Fully compatible
